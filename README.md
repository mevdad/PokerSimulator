# Poker Bots Arena

Симулятор кеш-игры в No-Limit Hold'em на чистом JavaScript (без зависимостей): сотни ботов садятся за несколько
столов, играют по стратегии из статьи [«Стратегія кеш-гри в покері» (Cardmates)](https://cardmates.ua/strategiya_kesh_gri_v_pokeri),
**сами принимают решения** по всем доступным данным и **обучаются** подбирать более прибыльную стратегию.
Игру видно визуально, есть рейтинг игроков.

## Запуск

```bash
# вариант 1: просто открыть index.html в браузере (сервер не нужен)
# вариант 2: локальный сервер
npm start                 # http://localhost:8080
# вариант 3: один автономный файл
npm run build             # -> dist/poker-bots-arena.html
# без интерфейса (быстрая статистика в консоли)
node sim.js --hands 50000 --bots 200 --tables 3 --seats 6 --seed 1
npm test                  # проверка движка
```

Параметры по умолчанию: **200 ботов, 3 стола, 6 игроков за столом, блайнды $0.25/$0.50 (NL50), рейк 3% (кап 3 ББ)**.
Всё настраивается кнопкой «⚙ Настройки» (боты, столы, места 2–10, блайнды, закупки, рейк, доля «рыб», обучение, seed)
или через адрес: `index.html?bots=500&tables=4&seats=9&speed=turbo&seed=42`.

## Режим «Компания vs Игроки» (по умолчанию)

* **Команда компании** — 200 ботов, которые учатся (эволюция). Стартовые гены — лучшие боты вашего прогона
  (`data/company-seed.json`; свои можно загрузить в «⚙ Настройки» из JSON кнопки «⭳ JSON»).
* **Игроки** — 200 ботов со **случайными seed**: seed определяет архетип (рыба, TAG, нит, LAG, маньяк, рок), все гены,
  закупку и поведение. Они не учатся. Seed виден в карточке игрока, поэтому любой состав воспроизводится.
* Боты компании играют **независимо**: общей информации, сигналов и «подыгрыша» между ними нет. За столом их не больше
  `maxTeamPerTable` (по умолчанию 2 из 6 мест), поэтому основной поток денег идёт от игроков.
* Рейк в этом режиме по умолчанию 0: прибыль компании = проигрыш игроков (можно включить в настройках).

### Что считается «долей компании от потока денег игроков»

Панель «Компания vs Игроки» показывает долю `прибыль компании / поток игроков` и сравнивает её с целью (по умолчанию 3%).
«Поток» можно выбрать:

| Определение | Что это |
| --- | --- |
| **оборот игроков** (по умолчанию) | сумма всех ставок игроков во всех раздачах |
| **закупки игроков** (drop) | сумма всех закупок игроков, включая докупки |

Для доли считается **95% доверительный интервал** по независимым отрезкам истории — цель считается достигнутой, если она
внутри интервала. На коротких прогонах интервал широкий: для надёжного вывода нужно десятки тысяч раздач.

### Эксперименты: разные размеры команды и числа игроков

Кнопка **«🧪 Эксперименты»** (или `node scripts/scenarios.js`) перебирает сетку: боты компании × игроки × лимит компании за
столом × число столов, с повторами на разных seed. Результат — таблица долей, bb/100 обеих команд, прибыли, интервалов;
строки отсортированы по близости к цели, любой вариант можно запустить вживую («▶ смотреть») или выгрузить в CSV.

```bash
node scripts/scenarios.js --company 50,100,200 --players 100,200,400 --max-team 1,2,3 --tables 3 --hands 30000 --repeats 2 --csv result.csv
node sim.js --versus --hands 60000 --players 200 --max-team 2     # один прогон со сводкой команд
```

Важно: на деньги влияет не размер пула ботов, а **число занятых мест** (столы × места × лимит компании за столом).
Пул 200 ботов даёт разнообразие и ротацию, но одновременно за столами сидят только 18 человек (3 стола по 6 мест).

## Что видно на экране

* **Столы** — места, имена, стеки, позиции (BTN/SB/BB/UTG…), карты (переключатель «Карты ботов»), ставки, банк,
  борд, последнее действие каждого игрока, подсветка того, кто ходит, и победителя. Клик по имени открывает карточку бота.
* **Рейтинг** — прибыль, bb/100, раздачи, VPIP/PFR, динамический стиль по статистике (Нит, TAG, LAG, Маньяк, Рыба…),
  тип стека (SSS/MSS/BSS), номер стола. Сортировка по любой колонке, фильтры, поиск.
* **Карточка бота** — вся статистика (VPIP, PFR, 3-bet, C-bet, fold-to-bet, WTSD, W$SD), график прибыли и **гены
  стратегии** — параметры, которые бот подобрал сам.
* **Графики** — прибыль лидеров и эволюция популяции (VPIP/PFR/агрессия по поколениям), лента событий.
* Скорость: от медленной (чтобы следить за каждым действием) до «Турбо» (тысячи раздач в секунду). Пробел — пауза.

## Как бот принимает решения

На вход бот получает **всё, что видно за столом**: свои карты, борд, банк, ставку к коллу, стеки всех игроков,
позиции, число активных игроков, улицу, **историю действий раздачи** и HUD-статистику оппонентов
(VPIP, PFR, агрессия, fold-to-bet — как в трекерах из статьи). Дальше:

* **Префлоп** — 169 стартовых рук ранжированы в перцентили; диапазон открытия зависит от позиции
  (`openBase + posSlope × позиция`, чем ближе к баттону, тем шире), отдельно считаются 3-бет на value, 3-бет блеф
  (низкие suited-тузы и коннекторы), колл, 4-бет, изоляция лимперов. Диапазон рейзера оценивается по его HUD
  и подстраивает решение. При коротком стеке — пуш/фолд по приближению к равновесию Нэша; решения «на все деньги»
  принимаются по эквити против диапазона.
* **Постфлоп** — Монте-Карло-эквити против **диапазонов оппонентов** (сужаются по их префлоп-действию, ставкам и
  рейзам на текущей улице и по статистике агрессии). Сравнение с пот-оддсами, value-бет, рейз, c-bet, полу-блеф с дро,
  чек-рейз/слоуплей, чистый блеф только если вероятность общего фолда оправдывает ставку; учитывается позиция и мультипот.
* **Банкролл и дисциплина** — размер закупки (SSS/MSS/BSS), выход по числу рук, стоп-лоссу и стоп-вину (тильт),
  **выбор стола**: боты ищут столы со слабыми игроками (широкий VPIP, убыточные) и избегают регуляров.

## Как бот «придумывает» лучшую стратегию

Стратегия каждого бота — **геном из 28 параметров** (`src/genome.js`): ширина диапазонов, размеры ставок, частоты
блефа и c-bet, пороги эквити, использование HUD, закупка, лимиты сессии, разборчивость в выборе стола.

* Стартовая популяция «эволюционеров» — разброс вокруг ABC/TAG-покера из статьи и других стилей.
* Каждые N раздач (по умолчанию 4000) худшие 15% ботов по bb/100 (со сжатием на малой выборке) **перенимают стиль**
  двух лучших: кроссовер генов + мутация. Лучшие остаются без изменений. У «переродившихся» сбрасывается HUD.
* Часть ботов (25%) — **фиксированные архетипы**, которые не учатся: рыба-станция, маньяк, нит, пассивный рок, LAG, TAG.
  Они нужны как «мясо» для эксплуатации и как ориентир: видно, кто у кого выигрывает.

## Структура

| Файл | Назначение |
| --- | --- |
| `src/evaluator.js` | оценка 5–7 карт |
| `src/preflop.js` | рейтинг 169 стартовых рук |
| `src/equity.js` | Монте-Карло эквити против диапазонов |
| `src/genome.js` | гены, архетипы, мутация, кроссовер |
| `src/bot.js` | логика решений бота |
| `src/table.js` | движок стола: блайнды, торги, сайд-поты, олл-ины, рейк |
| `src/simulation.js` | рассадка, выбор столов, обучение, рейтинг, история, команды и доля компании |
| `src/experiments.js`, `scripts/scenarios.js` | перебор вариантов (число ботов, игроков, столов) |
| `scripts/extract-seeds.js`, `data/` | стартовые гены компании из JSON прогона |
| `src/ui.js`, `src/main.js`, `css/` | визуализация |
| `sim.js`, `test/`, `scripts/` | консольный запуск, тесты, сборка, сервер |

Деньги считаются в центах (целые числа). Симуляция детерминирована при заданном seed.
